# 济南智链纵横人工智能有限公司官网

这是基于 `https://jingxizhigu.com/` 前端构建产物整理的企业官网项目，已替换为济南智链纵横人工智能有限公司的品牌、内容和案例素材。

当前包含：

- 响应式首页与企业信息页脚
- 公司 Logo、企业简介、主营业务和核心优势
- 5 个案例卡片及横向自动滚动展示
- 首页背景图、楼体展示图和本地字体资源

## 本地预览

在项目根目录执行：

```powershell
python -m http.server 8000
```

然后打开 <http://localhost:8000/>。

## 项目结构

- `index.html`：页面入口
- `customize.js`：企业内容、案例和模块显示逻辑
- `customize.css`：品牌样式和响应式覆盖
- `assets/`：页面脚本、样式、字体和图片资源

## 说明

当前目录是生产构建产物，不包含原始 Vue 源码、组件拆分和构建配置。后续如需持续开发，建议逐步重建为可维护的 Vue/Vite 源码工程。
